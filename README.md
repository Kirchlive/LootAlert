# LootAlert

**Add any item to watchlist and get notified when it drops or posted by raid.**

![LootAlert Banner](https://i.imgur.com/r5tkuty.png)

LootAlert is a lightweight addon for World of Warcraft Vanilla (1.12.1) that helps you track important items. Get instant alerts when your watched items drop from bosses, are looted by players, or announced in raid chat.

## Features

- 🎯 **Instant Alerts** - Get notified immediately when tracked items drop
- 🎨 **Modern UI** - Clean minimal alert window with rarity
- 🖱️ **Movable Window** - Simply click and drag to reposition
- 💬 **Easy Management** - Simple slash commands to add/remove items
- 🗑️ **Quick Remove** - Remove items from your watch list with one click
- 🔊 **Sound Alerts** - Optional audio notification (configurable)
- ⚙️ **Configurable** - Auto-close timer, tooltips, sound, and more

## Installation

1. Download and extract `LootAlert` to your `World of Warcraft/Interface/AddOns/` directory 
2. Restart WoW
3. Welcome Message: `LootAlert: v1.0.0 - /la for help`

- or load with Addon-Manager

## Commands

### Quick Add Item

**/la add [shift+click item] to your watch list!**

```
/la                    - Show help menu
/la info               - Show addon information
/la add [item]         - Add item to watch list
/la del [item]         - Remove item from watch list
/la list               - Show all watched items
/la config             - Show configuration options
```
```
/la scale [0.5-3.0]    - Set window scale
/la autoclose          - Toggle auto-close on/off
/la delay [1-60]       - Set auto-close delay in seconds
/la sound              - Toggle sound alerts
/la tooltips           - Toggle item tooltips
/la status             - Show current settings
```
